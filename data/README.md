# Data

This folder contains input and intermediate data files for the EGFR
virtual screening pipeline. Files are not tracked in this repository
due to size constraints.

## Files

| File | Generated by | Description |
|------|-------------|--------------|
| `egfr_raw_activity.csv` | Notebook 01 | Raw ChEMBL bioactivity records (IC50) for EGFR (CHEMBL203) |
| `egfr_clean_dataset.csv` | Notebook 01 | Cleaned dataset: one row per molecule (median IC50), outliers filtered, active/inactive labels assigned |
| `egfr_features_and_labels.csv` | Notebook 02 | Molecules with computed molecular descriptors and activity labels |
| `egfr_fingerprints.npy` | Notebook 02 | Morgan fingerprint matrix (13,518 x 2048 bits) — **not uploaded to this repository due to file size** |

## Reproducing the data

Run the notebooks in order (`01_dataset_construction.ipynb`, then
`02_molecular_representation.ipynb`) to regenerate all files locally,
including `egfr_fingerprints.npy`.

## Source

Bioactivity data retrieved via the ChEMBL REST API
(`chembl_webresource_client`), target CHEMBL203 (Epidermal Growth
Factor Receptor, Homo sapiens).
