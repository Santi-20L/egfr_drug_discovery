# Data

Input and intermediate data files for the EGFR virtual screening pipeline. 
Files are not tracked in this repository due to file size; run the notebooks in order to regenerate them.

## Files

| File | Generated by | Description |
|------|-------------|-------------|
| `egfr_raw_activity.csv` | Notebook 01 | Raw ChEMBL IC50 records for EGFR (CHEMBL203), 25,244 rows, including `standard_relation` and `data_validity_comment`; no filtering applied |
| `egfr_clean_dataset.csv` | Notebook 01 | Curated dataset: one row per standardized parent structure (12,425 molecules), median exact IC50 where available, majority-vote active/inactive label |
| `egfr_features_and_labels.csv` | Notebook 02 | Curated molecules with six molecular descriptors and activity labels |
| `egfr_fingerprints.npy` | Notebook 02 | Morgan fingerprint matrix (12,425 x 2048 bits). Not uploaded to this repository because of its file size |

## Reproducing the data

Run the notebooks in order (`01_dataset_construction.ipynb`, then `02_molecular_representation.ipynb`) to regenerate all files locally.

## Source

Bioactivity data retrieved via the ChEMBL REST API (`chembl_webresource_client`), target CHEMBL203 (Epidermal Growth Factor Receptor, Homo sapiens).
